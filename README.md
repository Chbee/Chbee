## 🧠 How I Work

- 이슈 발생 시 개인 판단보다 **재현 기준과 영향 범위를 먼저 정의**해 팀이 같은 출발선에서 문제를 보게 합니다.
- 하이브리드 이슈는 웹·앱·로그를 분리하지 않고 **통합 관점의 분석 흐름**으로 정리합니다.
- OS·기기 의존 이슈는 **검증 우선순위와 디바이스 전략을 설정**해 불필요한 테스트 비용을 줄입니다.
- 기술적 대응이 필요한 경우 **여러 해결 시나리오와 각 리스크를 명확히 제시**해 의사결정을 지원합니다.
- 수정 이후에는 단순 해결이 아닌 **재발 가능성·라이브 영향·예외 처리 범위**를 기준으로 마무리합니다.
